步行导航
最后更新时间: 2026年10月07日
输入终点，以用户当前位置为起点开始步行导航，提示用户每段行驶路线以到达目的地。
支持版本V8.26.0 起
。
使用示例
cat=android.intent.action.VIEW
dat=amapuri://openFeature?featureName=OnFootNavi&sourceApplication=aaa&lat=110&lon=36
